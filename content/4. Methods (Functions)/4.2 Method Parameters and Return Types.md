Let’s go in detail on **method parameters and return types in C#**, since these are core to writing flexible, reusable methods.

---

# 📌 1. **Method Return Types**

The **return type** of a method specifies what type of value the method sends back to the caller.

### **Examples:**

**Void method (no return value)**

```csharp
public void Greet(string name)
{
    Console.WriteLine($"Hello, {name}!");
}
```

**Method with a return value**

```csharp
public int Add(int a, int b)
{
    return a + b;
}

int sum = Add(5, 3); // sum = 8
```

**Expression-bodied method**

```csharp
public double Square(double x) => x * x;
```

- Use `void` if nothing needs to be returned.
    
- Any other type (`int`, `string`, `bool`, `double`, `object`) can be returned.
    

---

# 📌 2. **Method Parameters**

Parameters are **inputs you give a method** so it can operate on different values.

### **Basic Parameters**

```csharp
public void PrintMessage(string message)
{
    Console.WriteLine(message);
}

PrintMessage("Hello!");  // Hello!
```

- `message` is a **parameter**; `"Hello!"` is an **argument**.
    

---

### **Parameter Types in C#**

1. **Value Parameters (default)**
    
    - A **copy of the value** is passed.
        
    - Changes inside the method **do not affect the original variable**.
        

```csharp
void Increment(int x)
{
    x++;
}

int num = 5;
Increment(num);
Console.WriteLine(num); // 5
```

2. **Reference Parameters (`ref`)**
    
    - Pass the variable itself, so **changes affect the caller**.
        

```csharp
void Increment(ref int x)
{
    x++;
}

int num = 5;
Increment(ref num);
Console.WriteLine(num); // 6
```

3. **Output Parameters (`out`)**
    
    - Similar to `ref`, but **doesn’t require initialization** before passing. See [[Initialising Before Passing]]. And [[Difference Between Ref and Out]]
        

```csharp
void GetValues(out int a, out int b)
{
    a = 10;
    b = 20;
}

int x, y;
GetValues(out x, out y);
Console.WriteLine($"{x}, {y}"); // 10, 20
```

4. **Optional Parameters**
    
    - Have a **default value** if no argument is passed.
        

```csharp
void PrintMessage(string message = "Hello World")
{
    Console.WriteLine(message);
}

PrintMessage();           // Hello World
PrintMessage("Hi!");      // Hi!
```

5. **Params (Variable number of arguments)**
    

```csharp
void Sum(params int[] numbers)
{
    int total = 0;
    foreach (var n in numbers) total += n;
    Console.WriteLine(total);
}

Sum(1, 2, 3); // 6
Sum(5, 10);   // 15
```

---

# 📌 3. **Returning Multiple Values**

C# allows multiple return values using **tuples**:

```csharp
public (int sum, int product) Calculate(int a, int b)
{
    return (a + b, a * b);
}

var result = Calculate(3, 4);
Console.WriteLine(result.sum);     // 7
Console.WriteLine(result.product); // 12
```

---

# 📌 4. **Summary Table**

|Feature|Syntax / Example|Notes|
|---|---|---|
|Value parameter|`void Foo(int x)`|Default, passed by value|
|Reference parameter|`void Foo(ref int x)`|Modifies caller’s variable|
|Output parameter|`void Foo(out int x)`|Must be assigned inside method|
|Optional parameter|`void Foo(int x = 5)`|Default used if no argument|
|Params (variable args)|`void Foo(params int[] nums)`|Accepts any number of arguments|
|Return type|`int Foo()`|Can be `void` or any type|
|Return multiple values|`public (int sum, int product) Foo()`|Uses tuples|

---

✅ **Tip:**

- Use `ref`/`out` **only when necessary**; default to value parameters.
    
- Use optional parameters and `params` for **flexible method calls**.
    
- Tuples are great for returning **multiple results** cleanly.
