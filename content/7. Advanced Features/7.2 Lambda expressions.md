Let’s go through **lambda expressions in C#** — a concise way to define **anonymous functions**.

---

# 📌 1. **What is a Lambda Expression?**

- A **lambda expression** is an **inline, anonymous function**
    
- Can be **assigned to delegates or Func/Action types**
    
- Uses the **`=>` (goes to) operator**
    

### **Basic Syntax**

```csharp
(parameters) => expression
```

- If multiple statements, use **curly braces `{}`**
    

---

# 📌 2. **Example with a Delegate**

```csharp
public delegate int MathOperation(int x, int y);

MathOperation add = (a, b) => a + b;
Console.WriteLine(add(5, 3)); // 8
```

- `(a, b)` → parameters
    
- `a + b` → expression returned
    
- `=>` separates parameters from body
    

---

# 📌 3. **Lambda with Multiple Statements**

```csharp
MathOperation multiply = (a, b) =>
{
    int result = a * b;
    return result;
};

Console.WriteLine(multiply(4, 5)); // 20
```

- Use **curly braces** and **return** for multiple statements
    

---

# 📌 4. **Using Lambdas with Func and Action**

- **Func<T1, T2, TResult>** → returns a value
    
- **Action<T1, T2>** → no return value
    

### **Func Example**

```csharp
Func<int, int, int> subtract = (x, y) => x - y;
Console.WriteLine(subtract(10, 4)); // 6
```

### **Action Example**

```csharp
Action<string> greet = name => Console.WriteLine("Hello " + name);
greet("Alice"); // Hello Alice
```

---

# 📌 5. **Lambda Expressions with LINQ**

- Lambdas are heavily used in **LINQ queries**
    

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };
var evenNumbers = numbers.Where(n => n % 2 == 0);

foreach (var n in evenNumbers)
    Console.WriteLine(n); // 2, 4
```

- `n => n % 2 == 0` is the **predicate** lambda
    

---

# 📌 6. **Advantages of Lambda Expressions**

1. **Concise** → no need to define separate methods
    
2. **Readability** → especially with LINQ queries
    
3. **Type Inference** → compiler infers parameter types
    
4. **Functional Programming Style** → easy to chain operations
    

---

# 📌 7. **Summary Table**

|Feature|Description|
|---|---|
|Syntax|`(parameters) => expression`|
|Func|Delegate that returns a value|
|Action|Delegate that does not return a value|
|Use Cases|LINQ queries, callbacks, inline methods|
|Multi-line Body|Use `{ }` and `return`|

---

✅ **Tip:**

- Use **lambda expressions** for **short inline methods**
    
- Combine with **LINQ** for powerful, readable data manipulation
