the core building block for decision-making in your programs.

---

# 📌 1. **if Statement**

The simplest way to make a decision:

```csharp
int age = 20;

if (age >= 18)
{
    Console.WriteLine("You are an adult.");
}
```

- The condition inside `()` must be a **boolean** (`true` or `false`).
    
- Code inside `{}` runs **only if the condition is true**.
    

---

# 📌 2. **if-else Statement**

Add an alternative when the condition is false:

```csharp
int age = 15;

if (age >= 18)
{
    Console.WriteLine("You are an adult.");
}
else
{
    Console.WriteLine("You are a minor.");
}
```

---

# 📌 3. **if-else if-else Chain**

Check multiple conditions in order:

```csharp
int score = 85;

if (score >= 90)
{
    Console.WriteLine("Grade: A");
}
else if (score >= 75)
{
    Console.WriteLine("Grade: B");
}
else if (score >= 60)
{
    Console.WriteLine("Grade: C");
}
else
{
    Console.WriteLine("Grade: F");
}
```

- **Only the first true condition executes**.
    
- The `else` block is optional.
    

---

# 📌 4. **Ternary Operator (Short If)**

A compact form of `if-else`:

```csharp
int age = 20;
string status = (age >= 18) ? "Adult" : "Minor";
Console.WriteLine(status); // Adult
```

- Syntax: `condition ? valueIfTrue : valueIfFalse`
    
- Useful for **simple assignments or inline output**.
    

---

# 📌 5. **switch Statement**

Use `switch` when you have **one variable and multiple discrete cases**:

```csharp
char grade = 'B';

switch (grade)
{
    case 'A':
        Console.WriteLine("Excellent");
        break;
    case 'B':
        Console.WriteLine("Good");
        break;
    case 'C':
        Console.WriteLine("Average");
        break;
    default:
        Console.WriteLine("Other");
        break;
}
```

- **`break`** prevents “fall-through” to the next case.
    
- **`default`** runs if no case matches.
    

### **C# 8+ Switch Expressions (modern)**

```csharp
int score = 85;
string result = score switch
{
    >= 90 => "A",
    >= 75 => "B",
    >= 60 => "C",
    _      => "F"
};
Console.WriteLine(result); // B
```

- `_` is like the `default` case.
    
- Very concise for **value-to-value mapping**.
    

---

# 📌 6. **Logical Operators with Conditions**

Combine multiple conditions using:

```csharp
int age = 20;
bool hasID = true;

if (age >= 18 && hasID) // AND
{
    Console.WriteLine("Entry allowed");
}

if (age < 18 || !hasID) // OR
{
    Console.WriteLine("Entry denied");
}
```

---

✅ **Summary of Conditional Statements**

1. `if` → simple condition
    
2. `if-else` → two-way decision
    
3. `if-else if-else` → multi-way decision
    
4. Ternary `?:` → compact `if-else`
    
5. `switch` → multiple discrete cases
    
6. Combine conditions with `&&`, `||`, `!`
